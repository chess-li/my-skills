# Excel 工作簿与模板

本 skill 只处理本地工作簿文件的结构、数据、公式和验证，脚本按通用 Linux、macOS 和 Windows 设计。`spreadsheet` 负责独立 CSV/TSV；本 skill 不依赖云表格、网盘、登录或固定厂商应用。

## 工作流

1. **分类**：确定 XLS/XLSX/XLSM/XLTX 输入、输出扩展名、是否原位编辑，以及是否要保留宏、图表、外部链接、嵌入对象、模板和公式缓存。旧版 XLS 默认转换到 XLSX；未指定输出时按此例外交付现代格式。
2. **快照**：确认工作簿可打开，记录工作表、范围、合并、隐藏/冻结、行列尺寸、命名范围、图表、宏标记和外部链接。默认写到不存在的新路径；输入输出相同或输出已存在时停止并报告。
3. **读取**：公式视图使用 `data_only=False`，缓存值视图使用 `data_only=True`；两次读取都不保存。先报告行列数、字段、类型、缺失、重复、异常范围、时间覆盖和候选主键。
4. **选择路线**：简单 `.xlsx/.xltx` 可用 `openpyxl`/`pandas`；`.xlsm` 写回必须显式使用 `keep_vba=True`、可保真本地引擎或包级编辑；富工作簿和旧版文件优先本地引擎/OOXML。
5. **写出**：执行写入值和公式、清洗、合并/拆分、排序/筛选、工作表结构、格式、条件格式、数据验证、批注、图表、透视或模板填充。使用本次独占的临时文件和原子替换；固定暂存名已存在时不覆盖。原位编辑先留可恢复副本。
6. **验证**：重算公式并检查错误、缓存、范围、图表、样式和宏/模板部件；必要时渲染工作表。交付绝对路径、重算方法、保真结果和未验证项。

## 读取与分析

- 读取工作簿和工作表清单、范围、合并单元格、隐藏/冻结、行列尺寸、数据验证、条件格式、图表、批注、命名范围、外部链接和宏标记。
- 导入 CSV/TSV 时先由 `spreadsheet` 规则确定编码、分隔符、表头、空值、日期、数字和前导零；不确定列按文本保留。
- 每个派生结果回指输入范围、单位、来源和假设。外部数据使用 `Source Name`/`Source URL` 两列或 Sources 工作表。

## 公式、模型与格式

- 可表达的计算使用公式，不把派生结果硬编码成静态数字；显式保护零除、空值和错误值。跨版本兼容时优先 `SUMIFS`、`INDEX`、`MATCH`、`IFERROR`、`SUMPRODUCT` 等稳定函数，动态数组先确认目标引擎。
- 公式结果必须是数值而不是数字文本；单位写在表头，原始值不提前缩放。假设和硬编码数字写在批注或可见说明中。
- 新建填写模板要有简短说明、可编辑区域和一行真实格式示例；编辑现有工作簿遵循原有输入区域和格式，不改无关公式。
- 检查列宽不会显示 `###`；图表使用真实系列和类别；透视表不能用一张说明表冒充真实透视表。
- 财务模型把输入/假设、公式、跨表链接和外部链接区分标记；默认蓝色表示输入、黑色表示公式、绿色表示跨表链接、红色表示外部链接。金额单位写在表头，百分比按小数存储，原始值不提前缩放。

## 模板、宏与保真

- XLTX 沿用工作表、样式、命名范围、公式和示例区域，输出保持 `.xltx`；不能保留模板部件时停止或明确未保留。
- `.xlsm` 读写必须确认 VBA 部件未丢失；无法验证宏保真时不得声称保留。
- `data_only=True` 的工作簿不能保存；含图表、图片、形状、外部链接、嵌入工作簿或自定义 XML 时，高层库无法往返的部分改用本地引擎/OOXML，丢失内容必须先确认。
- 旧版 XLS 只在本地引擎支持且用户明确要求时回写；默认交付 XLSX，并保留原件和转换日志。

## 公式与交付门禁

- 含公式文件必须经过可用计算引擎重算，再扫描 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?`、`#N/A` 和缺失缓存。重算失败或只有独立验证副本时标为未验证。
- 抽查 2–3 个公式的输入、范围和预期值，再批量生成；禁止把表头、越界行或错误工作表纳入范围。
- 结构检查通过不能替代视觉检查。交付写明工作表、公式、宏、外部链接、图表和模板部件的检查结果。

## 随附资产

- `scripts/xlsx_tool.py`：基础创建、检查、导出和单元格编辑。
- `scripts/xlsx_tools.py`：公式重算与静态验证；`scripts/recalc.py`：跨平台重算入口，宏式 LibreOffice 路线超时后回退到 `xlsx_tools.py`；`scripts/office/validate.py`、`scripts/office/soffice.py`：包验证与本地转换。
- `references/finance/`：三表、DCF 和 comps 模型参考。
- 调用随附 Python 资产时使用 `python3 <skill_path>/scripts/<name>`；脚本不会自动安装依赖，安装命令使用 `pip3`。

## 工具、授权与边界

- 可用工具：`python3`、`openpyxl`、`pandas`、`markitdown`、LibreOffice/UNO 或等价本地引擎、标准 ZIP/XML 工具。缺少依赖时报告影响；需要安装时使用 `pip3`。
- 默认直接执行读取、分析、创建草稿和写新输出；编辑已有文件但保留原件后告知。输出已存在时默认停止并报告；用户明确授权覆盖或原位编辑后，先留可恢复副本再继续。丢弃宏/外部链接/嵌入对象、删除唯一原件或外部发送必须先确认。
- 输入损坏、依赖缺失、公式错误或验证失败时停止交付，保留错误证据和最后一个可验证产物。
