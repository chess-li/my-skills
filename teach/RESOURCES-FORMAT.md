# RESOURCES.md 格式

`RESOURCES.md` 是本主题的高信源集。讲解的知识从这里取，不凭模型记忆猜；见识从其中登记的社区来。

## 结构

```md
# {主题}资源

## 知识

- [书：《力量训练科学与实践》Zatsiorsky & Kraemer](https://example.com)
  周期化与适应的基础读物。用于：周期化、恢复、强度分区的一切问题。
- [文：Greg Nuckols〈该练多少？〉（Stronger By Science）](https://example.com)
  训练量里程碑的循证综述。用于：各肌群每周组数目标。

## 见识（社区）

- [r/weightroom](https://reddit.com/r/weightroom)
  高信噪比 subreddit， moderation 抵制伪科学。用于：计划点评、平台期排障。
- 本地：{健身房名}周二力量课
  用于：动作的现场指导反馈。
```

## 规则

- **只要高信源。** 一手资料、公认专家、同行评议、强 moderation 社区优先；营销包装成教育的一律不收。
- **每条必注。** 裸链接三个月后毫无用处。加一行：讲什么、何时取用。
- **按知识/见识分组。** 与 [SKILL.md](./SKILL.md) 的三支柱对应；一个资源只出现在一组也正常。
- **缺口要显式。** 使命所需领域暂无好资源 → 开 `## Gaps` 节列出，驱动后续寻找。
- **无情修剪。** 被证明错误、浅薄或偏离使命的资源删掉，不埋没。五个锋利来源胜过三十个平庸来源。
- **登记社区偏好。** 用户 opted out 加入社区 → 记在这里，后续会话不再反复提议。
