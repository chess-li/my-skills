# CSV、TSV 与分隔表格

本 skill 的对象是独立的 CSV/TSV 和用户明确指定为表格的分隔数据文件；实现只依赖 Python 标准库，可运行于通用 Linux、macOS 和 Windows。普通 `.txt` 的默认路由仍是 txt。`excel` 负责工作簿内部的表格、公式、样式和图表；本 skill 不依赖云表格、网盘、登录或固定厂商应用。

## 工作流

1. **分类**：确认输入/输出是 CSV、TSV，或用户明确指定按表格解析的分隔文件；普通 `.txt` 先走 txt。记录编码、BOM、分隔符、引用字符、转义规则、表头和是否需要字节级保真。输出 XLSX 时转交 `excel`。
2. **读取快照**：默认按 UTF-8（有 BOM 时按 UTF-8-SIG）读取；分隔符在逗号、制表符、分号和竖线中自动识别。识别结果不唯一、行宽不一致或编码失败时停止并要求显式指定。
3. **分析**：报告记录数、最大列数、字段名、列宽一致性、缺失、重复、类型、日期、异常值和候选主键；把推断类型与原始文本分开。
4. **处理**：执行排序、筛选、去重、连接、聚合、透视、清洗、分割合并或编码/分隔符转换。身份证号、邮编、SKU、账户号等看似数字的字段默认按文本保留。
5. **写出**：用户未指定时，默认生成逗号分隔 CSV、UTF-8 无 BOM、LF 换行；源数据有命名字段时写表头，没有命名字段时不猜表头。使用临时文件和原子替换。
6. **验证**：重新解析输出，核对记录数、字段值、列顺序、行顺序、空值、分隔符、编码和前导零，再交付绝对路径。

## 解析规则

- 使用 `csv.reader`/`csv.writer` 或等价表格库；以 `newline=""` 打开文件并启用严格引号处理。嵌入换行必须保留在带引号字段中。
- `csv.writer` 可能规范化引号形状；默认保证字段语义而非字节级相同。需要字节级保真时不要解析后重写。
- 行宽不一致、坏引号或解码失败时停止并报告位置；不要用 `split(',')` 解析字段。
- Excel 兼容输出显式使用 UTF-8-SIG；TSV 显式使用制表符；其他编码、换行或分隔符必须在交付记录中说明。

## 数据处理

- 可执行类型/日期解析、缺失处理、重复检查、异常值检查、排序、连接、聚合、透视和清洗；每个派生字段说明来源和假设。
- 保留列顺序、字段文本、行顺序、空值语义和编码；转换不会静默把长整数、日期或前导零改写。
- 生成给人填写的表格时写出表头、字段说明和示例数据；生成给程序消费的表格时遵循用户提供的 schema，不擅自增加列。
- 从 CSV/TSV 生成 XLSX、修改工作表或生成公式/图表时切换到 `excel`，不要在这里模拟工作簿。

## 随附资产

- `scripts/csv_tool.py`：标准库实现的编码、分隔符、记录数、列宽一致性检查和 CSV 转换。
- 调用脚本使用 `python3 <skill_path>/scripts/csv_tool.py`；不需要第三方依赖。输出 XLSX 的任务切换到 `excel`。

## 工具、授权与边界

- 可用工具：`python3` 标准库 `csv`、`pathlib`、`codecs`、`io`、`json`，以及 `pandas`。缺少依赖时报告影响；需要安装时使用 `pip3`。
- 默认直接执行读取、分析、清洗、创建草稿和写新输出；编辑已有文件但保留原件后告知。输出已存在时默认停止并报告；用户明确授权覆盖或原位编辑后，先留可恢复副本再继续。删除唯一原件或外部发送必须先确认。
- 输入不合法、列数不一致、依赖缺失或输出无法重新解析时停止交付，保留错误证据和最后一个可验证产物。
