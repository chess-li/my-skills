# PowerPoint 演示文稿与模板

本 skill 只处理本地演示文稿包、页面内容和视觉交付，脚本按通用 Linux、macOS 和 Windows 设计。它不依赖云演示文稿、网盘、登录或固定厂商应用。

## 工作流

1. **分类**：确定 PPT/PPTX/POTX 输入、输出扩展名、是否原位编辑，以及是否要保留模板、母版、主题、媒体、备注、批注、图表和嵌入对象。旧版 PPT 默认转换到 PPTX；未指定输出时按此例外交付现代格式。
2. **快照**：按放映顺序读取页数、标题、文本、表格、备注、媒体、图表、母版、版式、主题和嵌入对象。文件名中的 `slideN.xml` 不一定等于放映页号。
3. **规划**：新建先确定页面比例、主题字体、配色、留白、页面结构和每页主视觉；模板先识别可复用版式和占位符，不复制占位文案。
4. **选择路线**：新建可用 `pptxgenjs`/`python-pptx`；含备注、批注、母版、主题、嵌入对象或第三方扩展的已有文件用 OOXML 定点编辑或可证明保真的本地引擎。高层库会丢部件时先换路线。需要发布工作副本时用 `scripts/surgical/request_fold.py` 的本地文件路径和 CLI 参数，不依赖桌面 IPC。
5. **写出**：执行增删/复制/重排幻灯片、替换文字、更新表格/图表/图片/备注/批注、填充模板或调整版式。少量文字只重写目标 slide；使用临时文件和原子替换，原位编辑先留可恢复副本。
6. **验证**：检查内容类型、关系、页序、页数、图表、媒体、模板部件和文本；用 LibreOffice 转 PDF、用 Poppler 输出逐页图片后检查溢出、重叠、低对比、页边距、占位符、脚注和空白页。

## 本地生成、预览与发布

- 新建或大范围重建使用本地 `python-pptx` 或 PptxGenJS；两者都直接写标准 OOXML `.pptx`，不需要登录或在线演示文稿服务。
- 需要保留未建模部件时使用 `scripts/surgical/prep.py`、`edit.py`、`verify.py` 做 OOXML 定点编辑；不要把整包交给高层库往返。
- 预览用随附的 `scripts/office/soffice.py` 或本地 LibreOffice 转 PDF，再用 `pdftoppm` 生成 PNG。无法找到任一可执行文件时，将视觉验证标为未验证。
- 将工作副本写回目标文件时运行 `python3 <skill_path>/scripts/surgical/request_fold.py --source <working.pptx> --target <output.pptx>`；目标已存在必须显式加 `--force`，脚本会校验复制后的 SHA-256。

## 读取与分析

- 文本清单和缩略图/预览都要先生成，再选择页级或包级修改。
- 核对标题、单位、图例、坐标轴、页码、来源和叙事；图片图表无法提取底层数据时明确报告。
- 模板填充前区分模板槽位和源数据项；缺少源项时删除整个占位组，不能只清空文字。

## 创建与编辑

- 正式或视觉导向的演示文稿每页至少有一个有信息价值的图像、图表、表格、流程或形状；用户或模板明确要求文字页时保留文字页结构并检查信息层次。图表使用原生图表，流程/架构使用可编辑形状；列表使用列表属性，不把项目符号写进文字。
- 页面比例在添加页面前固定；文本框、字体、边距和留白要给渲染环境留下余量。备注放在备注部件，不能把备注伪装成页面文字。
- 修改已有 PPTX 的少量文字时，先确认文件没有被其他程序同时保存，再用页号与稳定文本定位的定点 XML 编辑。写盘前后检查页数和部件类别没有减少，保留未点名页面、媒体、字体、嵌入工作簿、扩展和加载项数据。
- 文本替换可以跨相邻 run，但保留 run 样式、软换行和列表层级；不要手工复制 slide XML 而跳过关系登记。
- 图表、备注、批注、母版、主题和嵌入对象只能由 OOXML 或能证明保真往返的本地引擎处理；高层库不支持时停止或明确标为未保留。

## 模板与视觉验证

- POTX 沿用母版、版式、主题和媒体关系；输出保持 `.potx`，清除占位文案并检查页序和主题部件。
- 验证内容类型、关系、页序、媒体目标和模板部件；不要移动演示文稿根 XML 的顺序敏感子元素。
- 渲染检查文字截断、元素重叠、低对比、页边距、脚注、图表标签和占位符。文本提取或 schema 检查不能替代视觉检查。
- 旧版 PPT 只作为输入；需要旧版回写时必须明确请求并由本地引擎验证，否则交付 PPTX 或停止。转换前后保留原件和日志。

## 随附资产

- `scripts/pptx_tool.py`：基础创建、检查、提取和文本替换。
- `scripts/add_slide.py`、`scripts/clean.py`、`scripts/thumbnail.py`：页操作、清理和缩略图；`scripts/office/validate.py`、`scripts/office/soffice.py`：包验证与跨平台本地转换。
- `scripts/surgical/prep.py`、`edit.py`、`pptx_parts.py`、`verify.py`：保留未点名部件的定点 XML 编辑与核对。
- `scripts/surgical/request_fold.py`：本地路径到本地路径的原子发布和冲突检查；支持单次参数或 JSON 操作文件。
- `references/local-alternatives.md`：本地生成、OOXML 编辑、预览和发布路线及依赖边界。
- 调用随附 Python 资产时使用 `python3 <skill_path>/scripts/<name>`；输入、输出和操作文件都由调用方通过路径提供。

## 工具、授权与边界

- 可用工具：`python3`、`pptxgenjs`、`python-pptx`、`markitdown`、`lxml`、标准 ZIP/XML 工具、LibreOffice 和 `pdftoppm`。缺少依赖时报告影响；需要安装 Python 包时使用 `pip3`。
- 默认直接执行读取、分析、创建草稿和写新输出；编辑已有文件但保留原件后告知。原位编辑、覆盖已有输出、丢弃媒体/备注/批注/嵌入对象、删除唯一原件或外部发送必须先确认。
- 输入损坏、依赖缺失、关系断链或视觉验证失败时停止交付，保留错误证据和最后一个可验证产物。
