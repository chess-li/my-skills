# 原型创建与对齐

## 意图锚点（每次使用前必读）

本 skill 守护一条主线：**差异出自空白——agent 只按写下的做，没写的自由发挥；对齐的职责是把感受变成可观测断言，不是把形容词写得更华丽。** 先锚定，再动手；用户给不出锚点就造变体——实物即锚。

对齐护栏：
- 模糊反馈不直接改：「效果不好」「左侧不对」类反馈先锚定；猜着改 = 制造下一轮差异
- 差异分类路由：行为差异（功能对错）→ 补 spec 验收条款（spec skill 的事）；视觉/交互差异 → 可观测断言（本 skill）
- 一次只改一个区域，改完当场对齐；整页重交付 = 重新制造全面差异

## 核心工作流

### 1. 分路

- 行为问题（功能对错）→ 走 <use-skill>spec</use-skill> 补验收条款，本流程结束
- 新建原型 / 方向不明（「该长什么样」）→ 第 2 步变体锚定
- 已有原型的效果反馈 → 第 2 步锚定谱系

产物：分路结论。

### 2. 锚定

**用户给不出锚点**（说不清要什么、无对标、新建区域）→ 变体锚定：同页造 3 个结构迥异的变体（至多 5 个），可切换对比，用户挑一个或拼几个。护栏：差异必须结构级（布局、信息层级、主操作），只差颜色文案 = 壁纸不是变体；变体嵌真实骨架与真实数据——真空里每个变体都好看。

**用户给得出锚点** → 按锚定强度从强到弱选，有强的不用弱的：

1. **截图**：参考产品或现状截图，圈出区域 + 一句话；密度、留白、层级一看即懂
2. **DOM 指认**：在现有原型上指认，用 DOM 位置（「侧栏第二组的会话项」），不用「那个列表」
3. **数值直给**：DevTools 里把 padding/字号/颜色调到满意，贴数值——效果问题八成是数值问题，给数值零歧义
4. **场景脚本**（交互类）：「点 A → 出现 B；按 Esc → 关闭」，一步一句，锚状态转移不锚感觉
5. **草图/ASCII**：只锚布局比例，适合新区域首版

产物：锚点到位，或已向用户要到锚点。

### 3. 方位词消歧

「左侧/上面」相对方位在多候选页面天然歧义——agent 没有用户的视野，只能猜。治理三选：

- **区域命名**：一次对齐名字（侧栏、会话列表、对话主区……），之后只用名字；名字的沉淀归 domains skill
- **截图红框**：方位词变绝对像素位置，整类歧义消失
- **复述指认**：动手前「你说的是包含项目会话列表的侧栏吗？」确认，成本一句话

### 4. 落成可观测断言

锚点转成断言：「侧栏收起宽 56px」「会话项只显示标题」「按 Esc 关闭浮层」。写不出断言 = 锚定不足，回第 2 步。产物：断言清单。

### 5. 逐区域实施与对齐

一次一个区域，改完当场给用户对齐；通过 → 下一区域。断言随实现沉淀到对应文档。产物：每区域一条用户确认。

## 术语→DOM 映射

区域名必须能 grep 到唯一 DOM。原型持续演进，样式类名随重构漂移，不作锚——锚点一律用专用属性：

- 每个已命名区域打 `data-term-anchor="sidebar"`（属性值 = 术语表中的区域名，全文件唯一）
- 组锚点（N 个元素同属一组）= 把成员包进一个容器盒，盒打 `data-term-anchor="组锚值"`；成员不带锚属性，归属由 DOM 包含表达。锚点视图模式「添加分组」自动包盒（成员须同父相邻）
- 术语条目直接绑定选择器：侧栏 = `[data-term-anchor="sidebar"]`
- 样式类名不参与锚定；样式重构时 `data-term-anchor` 不动

## 锚点服务（自举）

锚点视图模式的保存写盘依赖 prototype-anchor 服务（HTTP 面，127.0.0.1:8420）；首次涉及锚点工作时自举（已装则跳过第 1 步）：

1. 安装到本地 npm：

   ```bash
   # invocation
   npm link "<skill目录>/scripts/prototype-anchor"
   ```

2. 启动（停止/查看把 start 换成 stop/status；人手手动管理用同一脚本）：

   ```bash
   # invocation
   bash "<skill目录>/scripts/anchor-serve.sh" start
   ```

   启动幂等（已存活则直接退出）；服务无状态，无页面心跳约 2 分钟自动消亡，需要时重新 start 即可

原型接入锚点视图（客户端插件 anchor-view.js 由服务分发，卸载无副作用）：

- 零侵入：经服务打开 `http://127.0.0.1:8420/proto?abs=<页面绝对路径>`，响应自动注入客户端，源码零改动
- 一行接入：`</body>` 前加 `<script src="http://127.0.0.1:8420/__am_client.js"></script>`；删除本行即卸载，服务未起时静默无影响
- 术语三级回退：页面 `window.AM_TERMS` 预置 → 服务 `/__am_terms` 解析项目术语表 → DOM 现查
- 写盘防护：文件在磁盘变动后，已打开页面的 DOM 路径即失效——先在浏览器刷新页面再做保存/删除

## 归宿

- 对齐/选定完成 → 行为结论沉淀到 spec 或任务文件；视觉/拓扑结论留在原型（可观测断言），不进 spec
- 原型不演进为生产：正式实现时重写合入，不照搬（原型代码生于无测试、无抛光约束）
- 落选变体、切换器、一次性脚手架移除，不留坏死面

## 授权分档

- 直接执行：读原型代码、grep 锚点属性、起草断言
- 执行后告知：按已锚定断言修改原型、生成/移除变体、为区域补/删 `data-term-anchor`（含分组包盒与纯包装盒拆盒）、锚点服务自举（npm link、anchor-serve.sh 起停）
- 必须先确认：整页或多区域重写
