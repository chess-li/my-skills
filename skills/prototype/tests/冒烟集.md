## S1（分组=容器盒语义）

- 语料：「分组相较于直接标记锚点，只是多一步为这些元素增加一个更大的box元素」（2026-08-23 用户原话，证据日志升格区）
- 前置：原型锚点工作，用户要为多个元素分组
- 硬性：组锚点落成容器盒——盒打 `data-term-anchor`，成员不带锚属性、归属由 DOM 包含表达；不实现为成员各自携带分组属性
- 来源：2026-08-23 返工（首版实现为成员属性，用户当场纠正）

## S2（交互语义分岔不取默认）

- 语料：「点锚点 B 时锚点 A 的标签不应自动关闭」（2026-08-24 用户指出，证据日志返工区）
- 前置：实现交互（开关/模式切换/删除/点击响应）存在多种合理语义
- 硬性：动手前列出语义维度与候选取值（联动排他/并集、模式互斥/正交、点击精确指认/就近归父、失败提示/静默）请用户一句话点选；不静默选实现最便宜的默认
- 来源：2026-08-23~24 六连返工（排他开关、A/B 互斥、closest 就近归属等同一病灶）

## S3（写盘失败有可读出路）

- 语料：「原型设计时锚点无法保存」（2026-08-24 用户原话，证据日志返工区）
- 前置：锚点写盘失败（JS 渲染区无源码区间 / 磁盘变动后陈旧 DOM）
- 硬性：给出可读诊断与出路（先刷新页面再保存；JS 渲染产物锚其静态容器）；不让用户面对英文技术报错无路可走
- 来源：2026-08-24 返工（settings-panel path not found）

## S4（术语→DOM 用专用属性锚定）

- 语料：「为原型添加统一锚点」（2026-08-20 cake 会话主题，证据日志返工区）
- 前置：原型区域命名/锚定工作
- 硬性：锚点一律用 `data-term-anchor` 专用属性，样式类名不参与锚定（重构漂移即静默失效）
- 来源：2026-08-20 用户裁定（删「类名即标签」首版）

## S5（校验失败不静默）

- 语料：「点击这个原型中的锚点保存按钮没有作用」（2026-08-24 用户原话，证据日志返工区）
- 前置：表单/锚点信息框校验不通过
- 硬性：任何校验失败路径有可观测反馈（提示+聚焦缺失字段）；无静默 return 路径
- 来源：2026-08-24 返工（保存处理器空值静默 return，唯一零反馈路径）
