# teach 课程式教学

## 意图锚点

带用户**跨会话学会**一个主题，不是一次性讲懂（那是 <use-skill>eli5</use-skill> 的事）。学会靠三根支柱：

- **知识**：取自高信源，不凭模型记忆
- **技能**：交互练习 + 即时反馈环习得
- **见识**：真实世界实战（社区、同好），agent 替代不了

学习状态全部落当前目录文件（见下表），新会话只读文件即可续教。

护栏：

- 一课只教一件事，短到几分钟完成，给用户一个可带走的小赢——工作记忆很小
- 知识类内容降难度：难度吃掉理解所需的工作记忆；技能类内容加难度：effortful retrieval 才建长期记忆——检索练习、间隔复习、相关主题交错
- 流利≠记住：当下能复述是流利强度，长期留存才是目标，课程设计奔后者去

## 工作区文件

| 文件 | 作用 |
|---|---|
| `MISSION.md` | 用户学这个的**原因**，一切教学决策回溯到它。格式见 [MISSION-FORMAT.md](MISSION-FORMAT.md) |
| `RESOURCES.md` | 高信源清单（知识）与社区清单（见识），每条注「讲什么、何时用」。格式见 [RESOURCES-FORMAT.md](RESOURCES-FORMAT.md) |
| `lessons/NNNN-<名>.html` | 课：一次一节、自包含 HTML、序号递增——主产物 |
| `reference/*.html` | 参考卡：课的压缩结论（速查表/语法/流程），供日后查阅，排版打印友好 |
| `learning-records/NNNN-<名>.md` | 学习记录：已验证的理解、自陈的已有知识、被纠正的误解——算最近发展区的依据。格式见 [LEARNING-RECORD-FORMAT.md](LEARNING-RECORD-FORMAT.md) |
| `GLOSSARY.md` | 本工作区统一术语；立了词条，课与记录都遵守。格式见 [GLOSSARY-FORMAT.md](GLOSSARY-FORMAT.md) |
| `assets/*` | 课间复用组件：共享样式、测验部件、图示助手。复用是默认，新需求先做成组件 |
| `NOTES.md` | 用户表达过的教学偏好与助教随手记 |

## 工作流

### 1. 锚定 Mission

`MISSION.md` 未建或含糊 → 先访谈用户「为什么要学这个」，落到具体现实目标再动笔——使命含糊，课程必滑向抽象。使命随学习漂移属正常：与用户确认后更新 `MISSION.md` 并记一条学习记录。

### 2. 备课

`RESOURCES.md` 未覆盖本课所需 → 先找高信源补上（一手资料、公认专家、强 moderation 社区优先），课内论断尽量带引用链接。所需领域暂无好资源 → 在 `RESOURCES.md` 开 `## Gaps` 节如实记下，驱动后续寻找。

### 3. 出课

读 `learning-records/` 与 `MISSION.md`，挑最近发展区内最相关的一件教：比用户当前水平刚好难一点。课的要求：

- 一节只教一件紧绑 mission 的事；先讲够用的知识，随即进练习
- 排版清爽可回看（Tufte 式）；锚点链接到相关课与参考卡；推荐一条最高质量的一手资料供课后读；课尾提醒不懂随时问
- 写完用 CLI 打开给用户
- 动笔先读 `assets/` 复用组件；共享样式表是第一件组件——让课像一门课，不是一堆散页

### 4. 练习与反馈

技能靠练不靠听：课内嵌测验或轻量浏览器任务，或带用户走真实世界步骤清单。反馈环越紧越好：即时、能自动判就自动判。测验各选项等长（字数一致），不给格式线索。

### 5. 沉淀

满足其一记一条学习记录（覆盖≠学会，等有证据再记）：用户展现出能用的理解、自陈已有知识（记深度）、纠正了误解、使命漂移。可日后查阅的压缩结论更新进 `reference/`；新概念待用户能用对，再升进 `GLOSSARY.md`。

### 6. 见识

问题超出知识与技能（要判断力、要行情）→ 尝试回答后把用户引向高声誉社区（论坛/subreddit/本地同好班），登记进 `RESOURCES.md`；用户明确不想加入则尊重，记一笔不再提议。
