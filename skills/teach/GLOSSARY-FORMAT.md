# GLOSSARY.md 格式

`GLOSSARY.md` 是本教学工作区的统一语言。所有课、练习、学习记录都遵守其术语。建术语表本身即是学习：把概念压成紧定义，是用户理解了的证据。

## 结构

```md
# {主题}术语表

{一两句说明本术语表覆盖的主题。}

## 词条

** hypertrophy（肌肥大）**：
机械张力与代谢压力在反复训练中驱动的肌肉增长。
_避免_：增肌块头、变大

** progressive overload（渐进超负荷）**：
经由重量、容量或强度，系统性提高对肌肉的需求。
_避免_：更使劲、升级

** RPE（自感用力度）**：
1–10 自评该组有多难，10=力竭，8=还能再做两次。
_避免_：努力分、强度分
```

## 规则

- **用户懂了才立词条。** 术语表是压缩知识的记录，不是让用户读着学的词典。概念刚引入 → 等用户能用对再升进来。
- **要有主见。** 同一概念多个叫法 → 选定最好的一个，其余列为应避免别名。语言就是这样压缩的。
- **定义要紧。** 一两句。定义它**是什么**，不定义它做什么、怎么做。
- **定义里用本表已有词。** 词一入表，处处优先用它，包括其他词条的定义内部——复杂概念因此变得好懂。
- **自然成簇就分节**（如 `## 解剖`、`## 计划`）。词间本就 cohesive 时平铺即可。
- **歧义显式钉死。** 某词在更大领域被滥用时记下本工作区的口径：「本工作区中，『组』永远指正式组；热身单独记。」
- **理解加深就修订。** 第一周写下的定义到第六周可能是错的。原地更新，不留过期词条。
