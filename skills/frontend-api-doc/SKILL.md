# 前端对接文档生成

## 意图锚点（每次使用前必读）

本 skill 守护一条主线：**前端对接文档是派生视图**——生成动作是把现存对接面翻译为前端可消费的文档，不新立断言；断言的归宿是 spec。

护栏：

- 产物模板与表达分档（formData→表格、JSON/XML→代码块、错误码始终表格）的单一信源 = implement「前端对接文档模板」节——遵循，不复制进本文件
- 只生成/重建文档，不改代码与 spec

## 工作流

### 1. 定范围

用户指定上下文 → 只生成它；未指定 → 扫全项目，列出含前端可见接口（路由/控制器层）的上下文清单，告知用户后逐个生成。

### 2. 读现状

读该上下文的 spec（如有）与接口代码。

- spec 缺失 → 从代码生成，文档首行声明「信源 = 代码（本上下文未建 spec）」，并提示可经 <use-skill>spec</use-skill> 补建（补不补由用户裁定）
- spec 断言与代码不一致 → 停下报告差异；无论哪边对，断言修订走 <use-skill>spec</use-skill> 后再生成

### 3. 生成

按模板产出 `docs/contexts/<限界上下文>/<限界上下文>-前端对接.md`；旧版已存在 → 全量替换（派生视图重建即最新，无增量维护）。

### 4. 落盘即提交

git 仓库：一个上下文一份文档，生成即提交。

## 冷启动

项目无 `docs/contexts/` 时随第一份前端对接文档创建目录，不预建、不建索引。
