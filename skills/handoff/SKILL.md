# 会话交接

## 意图锚点（每次使用前必读）

本 skill 守护一条主线：**新会话只读交接文档即可开工，不查询源会话。**

护栏：
- 交接文档落 `{本会话临时目录}/handoff/<yyyyMMdd>-<topic>.md`，不进版本库。临时目录取本会话环境声明的临时工作目录，不写死 harness 名
- 有 issue/spec/design 只写路径，不复制正文
- 前会话根因/修法写入「线索」，接手后仍按目标 skill 自己复现
- 接手禁止查源会话 id、禁止翻会话库

## 核心工作流

### 1. 入口

- 本会话要交出（移交/交接）→ 第 2 步
- 执行移交到异 harness/异模型，或执行者交出后需回程验收 → 「跨环境执行移交与回程验收」节
- 消息含交接文档路径或交接提示词 → 第 5 步

### 2. 写文档

topic：用户指定则用；否则从目标压一行（去空白，≤40 字）。

```bash
# invocation
python3 "<skill目录>/scripts/path.py" "{本会话临时目录}" "{topic}"
```

写入该路径：

```markdown
# {topic}

- 项目：{绝对路径}
- 源会话：{id}（接手禁止查询）
- 目标：
- 已完成：
- 线索（非本会话根因）：
- 复现：
- 下一步：
- 相关路径：
```

缺项从本会话已知事实补，不问。产物：该文件存在且「目标」「下一步」非空。

### 3. 提示词

生成并交给用户（原样可粘贴）：

```
读 {绝对路径}，按「下一步」执行。不要查询源会话。
```

### 4. 启动

宿主能创建可交互新会话 → 用提示词作首条消息启动，执行后告知。无交互界面的拉起方式不算（一次性批处理执行拿不到后续输入）。不能 → 只交提示词。

### 5. 接手

读交接文档。按「下一步」加载对应 skill。不查源会话、不翻会话库。接手执行包：按 brief 与验收清单执行，按证据格式回写 issue，触停止表即 BLOCKED 返回，不硬猜。

## 跨环境执行移交与回程验收

**触发**：执行者在另一个 harness 环境（本宿主拉不起会话），或用户明确交便宜/弱模型执行。

**执行包**（交接文档替换为以下结构；issue/spec/design 只写路径）：

- brief：行为式目标 + 显式出界清单 + 约束逐字下传（从 spec/issue 原样抄，不转述）；执行者无本会话上下文、能力可能低于你——不写只有本会话才懂的话
- 验收清单：每条 = 验证命令 + 预期输出，自含可独立重跑（抄自 issue；抄不出 → 回 <use-skill>implement</use-skill> 第 2 步补）
- 证据格式：每条完成声称挂命令 + 关键输出原文；没跑的标「未验证」，不许外推报喜
- 停止表：同一失败第 2 次 → 现象与已试路径写入 issue → BLOCKED 返回；NEEDS_CONTEXT 同为合法终态——升级不受罚，硬猜是违规

**回程验收**（执行者交出后，本侧）：

- 逐条重跑验收清单命令比对输出（跑不了写明理由）；重跑失败、输出矛盾、样本量虚报 → 视同未完成，回 <use-skill>implement</use-skill> 第 4 步
- 「未验证」条不视同通过；无证据行的勾选不成立
- 评审模型不低于执行模型

## 授权分档

- 直接执行：写临时文件、生成提示词、读文档
- 执行后告知：启动可交互新会话
- 必须先确认：无
