# 会话交接

## 意图锚点（每次使用前必读）

本 skill 守护一条主线：**新会话只读交接文档即可开工，不查询源会话。**

护栏：
- 交接文档落 `{本会话临时目录}/handoff/<yyyyMMdd>-<topic>.md`，不进版本库。临时目录取本会话环境声明的临时工作目录，不写死 harness 名
- 有任务文件/spec/design 只写路径，不复制正文
- 前会话根因/修法写入「线索」，接手后仍按目标 skill 自己复现
- 接手禁止查源会话 id、禁止翻会话库

## 核心工作流

### 1. 入口

- 本会话要交出（移交/交接）→ 第 2 步
- 消息含交接文档路径或交接提示词 → 第 5 步

### 2. 写文档

topic：用户指定则用；否则从目标压一行（去空白，≤40 字）。

```bash
# invocation
python3 "<skill目录>/scripts/path.py" "{本会话临时目录}" "{topic}"
```

写入该路径：

```markdown
# {topic}

- 项目：{绝对路径}
- 源会话：{id}（接手禁止查询）
- 目标：
- 已完成：
- 线索（非本会话根因）：
- 复现：
- 下一步：
- 相关路径：
```

缺项从本会话已知事实补，不问。产物：该文件存在且「目标」「下一步」非空。

### 3. 提示词

生成并交给用户（原样可粘贴）：

```
读 {绝对路径}，按「下一步」执行。不要查询源会话。
```

### 4. 启动

宿主能创建可交互新会话 → 用提示词作首条消息启动，执行后告知。无交互界面的拉起方式不算（一次性批处理执行拿不到后续输入）。不能 → 只交提示词。

### 5. 接手

读交接文档。按「下一步」加载对应 skill。不查源会话、不翻会话库。

## 授权分档

- 直接执行：写临时文件、生成提示词、读文档
- 执行后告知：启动可交互新会话
- 必须先确认：无
