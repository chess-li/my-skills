# 学习记录格式

学习记录落 `./learning-records/`，顺序编号：`0001-slug.md`、`0002-slug.md`……目录惰性创建：第一条记录诞生时才建。

它们是教学版的 ADR：记录非显然的领悟、关键洞察、用户自陈的已有知识——供后续会话算最近发展区。

## 模板

```md
# {学到或确立了什么的短标题}

{1–3 句：学到了什么（或确立了什么已有知识），以及它为何影响后续教学。}
```

这就是全部格式。一条记录可以只有一段。价值在于记下「这已经会了」和「它改变了接下来教什么」，不在填满各节。

## 可选节

仅在确有增量价值时加，多数记录不需要：

- **Status** frontmatter（`active | superseded by LR-NNNN`）：早期理解被证伪并被替代时用。
- **证据**：用户如何展现出理解（答对了什么、完成了什么练习、援引的过往经验）。结论可能被复查时有用。
- **影响**：为后续解锁或排除了什么。非显然时值得记。

## 编号

扫 `./learning-records/` 现有最大编号，加一。

## 何时记

满足其一即记：

1. **用户对非平凡内容展现出真理解**：不是接触过，是有证据能正确使用——为「接下来教什么」抬高了地板。
2. **用户自陈已有知识**：「我已经会 X」——记下，后续会话不重复教；同时记自陈的**深度**。
3. **误解被纠正**：用户原先信错了，现在明白为什么错——高价值：预示相关主题的易错点。
4. **使命因学习而漂移**：用户发现自己在乎的和原以为的不同——交叉链接 [[MISSION.md]] 并更新它。

### 什么不算

- 仅仅讲过的材料。覆盖≠学会，等证据。
- 已在 [[GLOSSARY.md]] 里作为词条定义 terse 记录的内容，不重复。
- 逐课流水账。学习记录不是日记，是决策级洞察。

## 替代

后来的记录与先前矛盾（理解加深或被纠正）→ 旧记录标 `Status: superseded by LR-NNNN`，不删除。理解演化的历史本身是有用信号。
