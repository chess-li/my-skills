# 决策地图

本 skill 守护一条主线：**跨会话只恢复未决探索，不复制 spec、design 或 issue。**

## 工作流

1. 讨论能在当前会话完成时，不建地图。留在 spec 的讨论出口。
2. 探索会跨会话，且用户要持久恢复时，写入 `docs/explorations/<topic>.md`。topic 用用户给出的主题；没有则用目标压成短名。
3. 使用下面的槽位。决定已成为当前需求或技术事实时，在同一步交 spec、design 或 domains 接管，地图只留短标签和权威链接。不复制断言正文，也不把「尚未交回」留成第二份当前事实。
4. 需要事实调查时交 research。需要在选项中裁定时交 interview。可执行工作交 issues。未决问题不建 issue。
5. 下一问题必须是回来后可以继续问的一个问题。地图不作为第二份当前事实文档，也不作为第二份 issue 队列。

- 出界：

- 已决定：
  - 决定：短标签
  - 权威：已交回的 spec、design 或 domains 路径
- 下一问题：

## 授权

- 直接执行：阅读已有地图和权威文档链接
- 执行后告知：创建或更新 `docs/explorations/<topic>.md`
- 必须先确认：删除地图，或把未决问题写成 spec 断言
