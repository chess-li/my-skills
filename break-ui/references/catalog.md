# 极端数据目录

只选择业务上可能发生或由契约允许的值。每次记录字段来源和限制。

| 类型 | 示例 | 重点检查 |
| --- | --- | --- |
| 长姓名 | `Aleksandra Wiśniewska-Kowalczyk` | 换行、头像、行高 |
| 长邮箱或 URL | `bartholomew.fitzgerald@northwind-industries-holdings.example.com` | 断行、操作按钮可达 |
| 单字符 | `Jo`、`X` | 首字母、占位符、对齐 |
| 非拉丁文本 | 越南语、泰语、阿拉伯语 | 字体、行高、RTL |
| emoji 开头 | `🧪 Lab` | grapheme 分组、回退图标 |
| 缺少可选值 | 空标题、无头像、无角色 | 空行、破折号、布局高度 |
| 边界数字 | `0`、`1`、`1,284`、最大整数 | 复数、格式化、列宽 |
| 特殊数字 | `NaN`、`undefined`、负数 | 空值保护和显示策略 |
| 长标签 | 翻译后的按钮或状态 | 按钮宽度、徽标换行 |
| 空集合 | 0 行、无搜索结果 | 空态、容器高度 |
| 单集合 | 1 行、计数为 1 | 复数和边距 |
| 大集合 | 契约上限或约 1,000 行 | 滚动、分页、渲染成本 |
| 时间边界 | 刚刚、跨时区、闰日 | 本地化、溢出、排序 |
| 媒体异常 | 缺图、宽高比异常、加载失败 | 回退、裁剪、布局稳定 |
| 内容编码 | `<b>`、`&amp;`、Markdown 标记 | 转义层和原样显示 |

常见现象包括：flex 子项被压扁，文本列缺少 `min-width: 0`，不可断开的字符串溢出，徽标换行，操作按钮被推出视口，数字未本地化，缺省值留下孤行，固定高度截断内容，以及大列表滚动卡顿。报告中写出实际现象和代码证据，不把目录条目自动当成缺陷。
