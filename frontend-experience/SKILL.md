# 前端动效与移动 Web

本 skill 守护一条主线：**体验问题要有对应改动或有证据的审查发现，并如实写出验证范围。**

## 工作流

1. 判断触及面。动效读取 [动效核对](references/motion.md)。移动 Web 读取 [移动 Web 核对](references/mobile-web.md)。只触及一面时不读另一面。
2. 创建或改进时，改动对应核对项里失败的那一条。审查时，每条发现写元素、条件和观察到的行为。
3. 平台事实写适用条件。不确定的事实先核对一手来源。审美建议与平台事实分开。
4. 只验证了桌面浏览器或静态源码时，写明设备和视觉验证范围。不把该范围写成已在手机上验证。
5. 视觉方向交 prototype。极端数据交 break-ui。生产行为改动交 spec、design 和 tdd。

## 授权

- 直接执行：阅读界面代码和已有原型，起草发现
- 执行后告知：按核对项修改原型，或写出具体改动
- 必须先确认：发布，或在没有 spec 的情况下修改生产行为
