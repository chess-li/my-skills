# 三件套固定产物结构与 DOCX 模板映射

本文件只定义内容边界，不是 Word 模板。固定章节、固定段落、表格列、版式、分页、页眉页脚和目录字段全部以 `../templates/` 中的 `.docx` 文件为准，并由 `scripts/generate_rd_docs.py` 按 `../templates/report.json` 清单打开模板后填充。不得让模型或生成脚本依据本 Markdown 临时重建这些结构。

当前模板文件：

- `templates/01-立项决议-template.docx`
- `templates/02-项目计划书-template.docx`
- `templates/03-成果效用说明-template.docx`

模板使用标准 Jinja2/docxtpl 语法：普通字段使用 `{{ item.field }}`，表格循环使用独立行中的 `{%tr for item in items %}` / `{%tr endfor %}`，段落循环使用 `{%p for item in items %}` / `{%p endfor %}`，图片使用上下文中的 `InlineImage` 对象。不得使用自定义 `ROW/BULLETS/IMAGE` 标记。

## 通用版式

- A4 纵向；封面、目录、正文、表格和页码使用稳定的 Word 样式；
- 标题使用黑体或兼容黑体，正文使用宋体或兼容宋体；
- 使用真实标题样式生成目录，不用手工输入目录页码；
- 图表使用连续编号和图注，图片不拉伸，不让图注单独落页；
- 客户版只写项目事实、研发方案、过程和成果，不写内部评分、风险等级或材料缺口诊断。

## 01-立项决议.docx

固定顺序：

1. 封面/标题：`关于〈项目名称〉的立项决议`；
2. 承担单位与决议日期；
3. 审议事项：项目立项申请；
4. 决议正文：同意立项、项目目标和主要研究内容、项目负责人及团队、研发周期、预算及费用构成、经费来源、预期成果、组织实施授权；
5. 落款：承担单位、公章、决策机构或授权人、日期。

事前边界：只能写批准开展的目标、内容、资源和预期成果，不写已经取得的检测结果、销售收入、专利授权或完成结论。会议、地点、主持人、参会人等字段没有来源时使用 `Hxx`，不得虚构。

## 02-项目计划书.docx

严格使用以下一级目录，不新增其他一级章节：

1. 第1章 立项依据
   - 1.1 立项背景
2. 第2章 项目目标与方案
   - 2.1 研发目标
   - 2.2 方案设计
   - 2.2.1 至少三条真实技术主线；标题使用实际技术课题名称
3. 第3章 项目难点与技术不确定性
   - 3.1 项目难点
   - 3.2 项目技术不确定性
4. 第4章 现有研发条件和工作基础
   - 4.1 公司优势
   - 4.2 人员优势
5. 第5章 计划进度
6. 第6章 项目编制及研发人员名单
7. 第7章 经费预算

每条技术主线固定写课题标题以及：现有问题、研究目标、研究内容/试验思路、变量或参数、验证方式、预期效果六项方案内容。第5章使用“计划时间—阶段—主要研发内容—阶段成果/输出物”表格；第6章使用“姓名—部门/岗位—项目职责—工作内容”表格；第7章使用“费用分类—预算金额—主要用途”表格。

## 03-成果效用说明.docx

严格使用以下一级目录：

1. 第1章 项目研发的整体概述
   - 1.1 项目研发目的及意义
   - 1.2 项目研发的技术创新点
2. 第2章 项目研发成果综述
   - 2.1 实现的技术指标与关键参数
   - 2.2 研发具体成果展示
   - 2.2.1 研发成果归属
   - 2.2.2 研发成果展示
3. 第3章 研发项目经济及社会效应
   - 3.1 社会效益
   - 3.2 经济效益
   - 3.3 应用成果

事后边界：只能写实际完成的研究、结果、指标、知识产权、检测/验收、应用和效益。每项成果要能映射到计划书目标或统一底稿；只有预计、计划或目标性质的内容必须明确写成“预计/计划”，不能伪装为已完成。

## 三文档投射关系

| 统一要素 | 立项决议 | 项目计划书 | 成果效用说明 |
|---|---|---|---|
| 项目身份、主体、负责人、周期 | 必须 | 必须 | 必须 |
| 背景与必要性 | 简写 | 完整 | 回顾 |
| 研究目标与指标 | 预期 | 完整 | 完成情况对照 |
| 技术路线与研究内容 | 概述 | 核心 | 实际开展与成果 |
| 难点与不确定性 | 不展开 | 核心 | 结果中说明如何验证/解决 |
| 人员与预算 | 必须 | 完整 | 仅说明实际投入或来源支持的内容 |
| 成果、效用、知识产权 | 预期形式 | 预期形式 | 实际成果与证据 |
