# Skill 创建

## 意图锚点（每次创建前必读）

本 skill 守护一条主线：**把设计纪律在创建期走完，让新 skill 以最小上下文、可预测行为进入使用期。** 创建的目标不是写得完善，而是触发、上下文、结构三处不欠债——欠债会在迭代期加倍偿还。

创建护栏：
- 先定调用方式再动笔；仅手动调用的 skill 不写 description（零常驻成本）
- description 写本质能力与判别边界，不枚举用户说法（说法是无穷的）
- 正文每句话过审计四问；模型已知的一律不写
- 冒烟集与 skill 同期建成，不等使用期补建

## 核心工作流

五步，顺序不可跳过：

### 1. 定调用方式

- 需 agent 自动触发或被其他 skill 调用 → model-invoked，保留 description
- 仅人手动调用 → user-invoked，去掉 description，人即索引；手动 skill 多到记不住时用一个 router skill 做目录

### 2. 写 description（model-invoked 时）

结构 = 本质能力 + 类别级锚点（≤4 个代表例，可含管辖产物的字面名）+ 负向边界（"不用于 X，那是 Y skill 的事"）。自查：

- 每句都贡献触发判别吗？纯身份描述 → 删
- 在枚举用户说法吗？→ 收敛为类别锚点
- 与相邻 skill 用负向边界划界了吗？

### 3. 按差值原则写正文

逐段过审计四问：没有这句模型也会做对 → 删；知道但会忘 → 压成清单短句；不知道 → 写成明确知识；必须每次精确一致 → 挪进 scripts。

结构约束：workflow 一条主干 ≤7 步，锚定产物不锚定状态；授权分三档，常见决策点写死默认值。

### 4. 选词过双闸

闸一·招募共识：优先复用模型/行业/社区/大众共识里已有的概念，自造词是最后手段，一旦造词定义必须显式写入。闸二·招来的干净：联想恰好等于所需含义，无隐藏副作用。禁令配正向目标，每个含义单一信源。

### 5. 建创建期冒烟集

摘 3–5 条真实语料输入（含口语、错字、半截话），断言指向交付物价值而非步骤服从。方法与模板见 [../shared/testing-guide.md](../shared/testing-guide.md)。

## 交付判据

- SKILL.md 存在，name 与目录名一致，description ≤1024 字符
- 正文每句可归入审计四问的某一档
- 冒烟集已预置在固定目录

## AI 生成偏差（自查）

AI 起草 skill 有四个已知偏差：加法偏好（一次写全）、教科书化（枚举说法、文档腔）、拆分偏好（以拆文件代替删减）、形式化偏好（状态机外观）。逐项自查；完整清单与对策见 skill-iteration-review「AI 协作的四个已知偏差」。
