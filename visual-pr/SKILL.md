# 变更结构说明

本 skill 守护一条主线：**让评审者看到这次 diff 改变了哪条结构，而不是逐文件流水账。**

## 工作流

1. 读取基线与当前 diff，以及相关 spec。没有基线 diff 时停止，并说明缺少 diff。不根据当前代码编造变更前。图和表里的每个关系都要能指到 diff 中的符号或文件。指不到的不画。
2. 变更很小时，只写意图、受影响位置和未知项。
3. 复杂变更最多用 1–2 个能降低阅读成本的 Mermaid 图或小表。不用 HTML，不截图，不自动提交。
4. 说明包含：意图、变更前、变更后、受影响契约或调用路径、已有验证证据、未知项。没有证据的验证写未知，不编造。
5. 正确性仍由 code-review 裁决。本说明不授权推送、发布或合并。

## 授权

- 直接执行：阅读 diff 和 spec，起草说明
- 执行后告知：把说明写入用户指定的位置
- 必须先确认：推送、发布、合并，或修改产品代码
