## 工作流用例

```
用例 ID: R01
用户处境: 变更写完，提交前想要独立把关
真实输入: 改动写完了，提交前帮我看看有没有问题
验收标准:
  - 硬性: 完整评审在新鲜上下文中进行（评审者拿不到实现过程的会话历史），实现者自审不充当裁决级评审
  - 硬性: 产出分级发现（P0–P5 带 file:line）与明确裁决（可合入 / 修复后重审）
  - 硬性: 单纯 review 场景仅报告发现与修复建议、询问是否修复，不自动修复
  - 软性: 发现指向真实问题，无"看起来不错"式空评
来源: 扰动变体
```
