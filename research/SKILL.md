# 资料研究

本 skill 守护一条主线：**每个可行动的结论都能回到拥有该事实的一手来源。** 研究结果是带来源的 Markdown 文件，不是会话中的无出处摘要。可引用的结论只写在一份入口里，不写在来源材料里。

## 核心工作流

### 1. 收口问题

写出研究问题、范围、目标版本或日期、需要支持的决策和明确不查的内容。问题清楚时直接开始，不为形式追问。

### 2. 选择一手来源

按以下顺序查找：

1. 当前仓库的代码、测试、配置和已有设计文档
2. 官方文档、规范原文、维护者源码和一手 API
3. 版本发布说明或官方 issue

二手文章只用来发现关键词。结论要有一手来源；多份二手一致仍不构成支持。读取时记下版本、发布日期或访问日期。

### 3. 建立取证回路

资料较多或需要继续推进主任务时，派只读子代理分组调查。每个调查者只负责一个问题角度，返回来源、证据位置和未决项；主会话保留最终判断。子代理返回留在会话中，核实后才写入入口或来源卡。

每条记录至少包含：主张、来源、来源位置、版本或日期、证据摘录或代码符号、置信状态。这些字段只留在会话，不另建证据表。核实后的主张只按第 5 步写进入口，不在研究文件里再写一份记录。把事实、推断和未验证项分开。

### 4. 交叉核对

对关键结论至少做一次交叉核对：源码与文档、规范与实现、或两个独立的一手来源。发现冲突时保留冲突，不静默选一个。各来源范围和采用理由只写进入口的冲突节。

### 5. 写研究文件

仓库已有研究目录则沿用；没有则用 `docs/research/`。下文路径相对于该目录。topic 用能区分问题的短名，不用技术总称。

研究目录里还没有任何入口 → 直接新建。已有入口时只走下面一条：

- 同一问题、同一目标版本、未过期（含没有过期条件的已有入口）→ 更新该入口，不另建。
- 同一问题、同一目标版本、过期已发生 → 重查来源后改同一入口，不新建 topic。
- 同一问题、目标版本不同 → 新建 topic，只在该旧入口写 `已被取代：<新入口路径>`。
- 问题不同 → 新建 topic，不改其他入口。

目录谓词只有一条：用户明确还会再用这次结论，或摘录长到会淹没结论。否则只写 `<topic>.md`。不用「以后可能用到」建目录。

- 不满足目录谓词 → `<topic>.md`。该文件就是入口。
- 满足目录谓词 → `<topic>/<topic>-summary.md`。目录与入口同时建立。`<topic>-summary.md` 只写当前可引用结论，不是笔记归集，也不是有损摘要。已有单文件且本次满足目录谓词 → 改为该入口，不保留两份结论。
- 已经是目录入口，且摘录会淹没结论或要保留冲突原文 → 卡写在 `<topic>/reference/<source>.md`。来源卡不单独触发建目录。稳定官方 URL 写在结论旁，不建卡。
- 写完后，含 `*-summary.md` 的 topic 目录不少于两个 → 研究目录根部有 `README.md`，为每个这样的目录各写一行：问题一句话、调查日、入口路径、有效或已被取代。建索引时不补单文件入口，不改那些目录里的文件，不收录任务清单或台账。只有一个 topic 目录时不建索引。

✅ 一次字段核对、两份官方文档、不回访 → 只写 `<topic>.md`
❌ 同一次核对再建目录、`*-summary.md`、`reference/` 和 `README.md`

本次只写本次调查的入口、谓词成立的来源卡，以及因此需要更新的索引。不清理研究目录中已有的其他文件。

入口按此顺序：

1. 题头：调查日、目标版本、过期条件、支持的决策、不决定什么。过期条件只写来源本身的变化，如被引用规范改版
2. 问题与范围
3. 结论：每条主张紧邻置信（事实 / 推断 / 未验证）、来源（URL、`file:line` 或来源卡路径）、以及「无冲突」或「见冲突」
4. 冲突：无则写「无」。有则只在这里写各来源范围和采用理由，落选来源保留，不重写行动结论
5. 未决：只写还不知道的事实
6. 来源：只列 URL、`file:line` 或来源卡路径，不重复主张

来源卡只写：定位、版本或访问日、一手或二手、短摘录或代码符号、不能支持什么。不重写主张，不写行动结论，不写置信。摘录保持能复核的最短长度；仓库外已有文件写路径。

本次已知结论被其他文档采纳时，入口加一条路径指针，不记录落地状态。未决不转成任务。用户要求执行的后续动作告诉用户，不写进研究文件。研究文件停在主张与来源。用户要的是行为断言、技术方案或术语定义时，告知分别归 spec、design、domains，不在本研究里写。

### 6. 交付检查

逐条检查：结论是否只在入口、是否能由来源支持、来源是否为一手、版本或访问日是否明确、推断和未验证是否标明、过期条件是否写出、未决是否只是未知事实。无法核实的内容写「未验证」和原因，不写成事实。本次新增的目录、来源卡和索引都满足第 5 步谓词。

## 默认授权

- 直接执行：读取仓库和公开一手资料、派只读调查、起草研究入口、来源卡和索引
- 执行后告知：在仓库新增或更新这些文件
- 必须先确认：付费资料、登录账户、对外发布研究结论、修改生产代码、把全文或二进制复制进仓库
